# 04 PID 调参与验收问答

## 一、调参流程（任务五，预留 3.5 小时）

**前提**：电机架空、CAN 反馈正常（Synex 通道 1-3 有数据、无报错音 2）。

目标：电机在 **2 秒内完成整个 0° → 90° → -90° 序列**（代码按 100ms@0° → 700ms@90° → 1200ms@-90° 分配，2 秒一循环）且不过分震荡。

> 代码会通过 **Synex 通道 7** 上报"到位标志"：本轮 0°→90°→-90° 都进入 ±5° 并保持 50ms 后为 1。可作为"2 秒内完成"的**机器判据**（配合通道 4/5 的实际曲线一起看）。

1. **先看原始反馈**：Synex 曲线里确认 角度(通道2)/转速(通道3)/电流(通道1) 都在动；
2. **只调 Kp**：从默认 0.5 开始，每次 ±0.1~0.2，用 `kp=0.7` 发送；
   - 到位太慢 → 加大 Kp；震荡 → 减小 Kp；
3. **再加 Kd**（阻尼）：出现超调/震荡时，`kd=0.02` 起步逐步加到 0.1 左右；
4. **最后加 Ki**（消除静差）：停在目标附近差几度 → `ki=0.05` 起步，**不要超过 0.5**；
5. 记下最终参数，回填到 `Control/motor.c` 的 `PID_DEFAULT_KP/KI/KD`，重新编译固化。

**任何时候输出电流撞到限幅（曲线顶到 ±4A）都先降 Kp，不要调大限幅。**

## 二、常见现象对策

| 现象 | 对策 |
|---|---|
| 电机完全不动 | 查 CAN（报错音2?）；Synex 看有无反馈 |
| 转到目标就大幅震荡 | Kp 减半；加 Kd |
| 到位后小幅抖 | Kd 太小或太大；微调 |
| 差一点到不了目标 | 加 Ki；检查积分限幅 |
| 一上电就冲一下 | 正常（上电位置=0°，先到 0° 再转 90°）；可等 2 秒再看 |
| 电流一直在 ±4A 顶格 | 机械卡死或 Kp 过大；立刻降 Kp/断电 |

## 三、验收问答速记（必背）

**1. 角度换算**
- 编码器一圈 **8192** 个计数 ↔ 转子 360°；
- 转子机械角 = 计数 × 360 / 8192；
- 跨圈累计：两次采样差 >4096 视为反向过零，±8192 修正。

**2. 减速比**
- M3508 减速比 = **3591 : 187 ≈ 19.2 : 1**（转子转 19.2 圈，输出轴转 1 圈）；
- 输出轴角度 = 转子角度 ÷ 19.2；
- 输出轴转速 = 转子转速 ÷ 19.2。

**3. 转速单位**
- CAN 反馈的是**转子** RPM（转/分）；
- 输出轴角速度 °/s = 转子RPM × 360 ÷ 60 ÷ 19.2。

**4. 电流（转矩）换算**
- C620 电流量程 **±16384 ↔ ±20 A**；
- 1 A = 16384/20 = **819.2** 个原始值；
- 控制帧 0x200：本电机电流 2 字节、高字节在前；
- 反馈帧 0x200+ID：角度(2) 转速(2) 电流(2) 温度(1)。

**5. PID 结构**
- 位置式：`输出 = Kp·e + Ki·∫e·dt + Kd·(de/dt)`；
- 本项目 **D 项作用于反馈量**（避免目标跳变冲击），固定 1 kHz 计算；
- **积分限幅 + 输出限幅**：防积分饱和、保护机械（任务书明确要求）。

**6. FreeRTOS 架构**
- 5 个任务：电机控制(1kHz, 最高优先级)、Synex 通信(10ms)、蜂鸣器(10ms)、LED(10ms)、舵机(20ms)；
- 分层：Core → BSP → Protocol/Control → App，任务间用消息队列解耦；
- CMSIS-RTOS V2 API（osThreadNew / osMessageQueue / osDelay）。

**7. CAN 基础**
- 1 Mbps 标准帧；C 板端有 120Ω，远端 C620 拨 ON；
- ID 由电调绿灯闪烁次数确定；ID 1→控制 0x200 / 反馈 0x201。

## 四、验收演示脚本（30 秒版）

1. 上电：蜂鸣器启动音 + LED 流水 + 舵机扫动（任务一/二/三）；
2. Synex 连接：三条曲线在动（任务四发送侧）；
3. 发送 `kp=0.1`：回显 0.1（任务四接收侧）；
4. 发送乱码指令：报错音 1；
5. 观察电机 0→90→-90（任务五）；拔掉 CAN 线：报错音 2 + 电机立即停（安全设计加分项）；
6. 打开 GitHub 仓库页面展示 commit 记录。
