# 01 接线与上电自检

> 进实验室第一件事：**接线 -> 自检 -> 再上电**。任何一步不对都先断电再改。

## 一、完整接线图

```text
                    ┌──(XT30)──> C620 电调 ──三相线──> M3508 电机
TB48S 电池(22.8V) ──┤
                    └──(XT30)──> C 型开发板        （板子必须接电池，USB 带不动电机/舵机）

C620 控制线 ──> C 板 CAN1 口（黑=CAN_L，白=CAN_H；多余的线悬空）
MG996R 舵机 ──> C 板 PWM 第1路（C1=信号黄/白线，B1=5V 红线，A1=GND 棕/黑线）
CP2102   ──> C 板 4-pin UART 口（外壳丝印"UART2"=USART1）
ST-LINK  ──> C 板 SWD 口（SWDIO/SWCLK/GND + 3.3V 参考，不给板子供电）
```

## 二、接线细节对照表

| 连接 | 细节 | 常见错误 |
|---|---|---|
| CP2102 ↔ C 板 UART2 口 | TX↔RX **交叉**，GND 接 GND；CP2102 的 5V/3.3V **不接** | 直连不交叉；不共地 |
| C620 控制线 ↔ C 板 CAN1 | CAN_H 接 CAN_H，CAN_L 接 CAN_L | 接反；接到 UART 口 |
| C620 ↔ 电池 | XT30 注意正负极 | 反接烧电调 |
| C620 ↔ 电机 | 三相三根粗线 | 无 |
| 舵机 ↔ C 板 PWM 口 | 信号/5V/GND 三根都要接对 | 只接信号线不接电源 |
| ST-LINK ↔ C 板 | 4 根线，SWD 口丝印顺序见板子 | 用 ST-LINK 给整板供电 |

## 三、上电自检顺序

1. **断电状态**接好所有线，检查一遍极性；
2. C620 的 **120Ω 终端电阻拨到 ON**（单电机，C 板端已有一个，两端各一个才标准）；
3. 开电池 → C 板电源灯亮；
4. **看 C620 绿灯闪几下 = 电调 ID**。闪 1 下 = ID 1（代码默认）；
   如果不是 1，改 `Core/Inc/board.h` 的 `MOTOR_ID` 后重新编译烧录；
5. 烧录程序 → 蜂鸣器响启动音（两声短音）→ RGB 灯开始流水 → 舵机开始扫动。
   三项都出现 = 板级基础 OK；
6. 观察 LED：若某颜色不亮，先检查 TIM5 三通道对应的三个灯珠是否被遮挡（板载灯很小）。

## 四、安全红线（务必遵守）

1. **电机首次上电必须架空/不装任何负载**，代码默认电流限幅 4A，调 PID 期间不要调大；
2. **动力线不要带电插拔**；6S 电池短路电流极大，先接板端再接电池端；
3. **C620 不能同时接 CAN 控制和 PWM 控制**，切换前先断电；
4. 蜂鸣器连续响"低音两长声"= 电机反馈失联，检查 CAN 线和终端电阻，不要硬调 PID；
5. 舵机堵转会持续吃大电流（MG996R 堵转可达 2A+），手不要硬掰，测试间隙让它回中位；
6. TB48S 是智能电池：长期不用会自动放电，用前确认电量；收工先关电池再拔线；
7. 结束时**关电池、关遥控器、关 Synex 连接**再离开（考核扣分项）。

## 五、常见现象速查

| 现象 | 原因 | 处理 |
|---|---|---|
| 蜂鸣器/LED/舵机全无反应 | 没烧进去 / 板子没上电 | 看 ST-LINK 烧录日志；查电源 |
| 蜂鸣器响但 LED 不流水 | 任务崩溃？ | 重新烧录；看 `docs/02` 断点调试 |
| 舵机嗡嗡响但不动 | 供电不足或信号错 | 确认接 5V 那根线；测 PWM 口电压 |
| 串口收到乱码 | 波特率/地线 | Synex 与代码都设 115200；共地 |
| Synex 无数据 | 协议/COM 口选错 | 先 RawData 看有无字节流 |
| CAN 报错音 2 | 总线不通 | 查终端电阻、CANH/CANL、电调 ID |
